An entry for the make.fun competition "One Line, One Chill": a single horror
sentence, under 200 characters, meant to frighten a reader in one breath.

> I watched the baby monitor as I walked up the stairs — and saw myself already standing over the crib.

The scare is earned by the turn, not announced: no mirror, no doll, no
basement, no gore — just the quiet impossibility of being in two places at
once, with the last word landing the blow.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
The output is deterministic: byte-identical on every run. Python 3.13,
standard library only, no network access.
